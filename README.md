#### 👋 About

I studied AI & Robotics, and I've ended up somewhere between machine learning and hardware. Most of my work comes down to one question: *can we trust this number?* That number might be a reading from a sensor on an aerospace part, or a pixel in a satellite temperature map.

I like problems where physics meets code: sensor drift, ocean fronts, noisy signals that need cleaning up before anyone can rely on them.
